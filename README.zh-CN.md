# AtomVLA 开源项目

本仓库包含现有的数据转换与标注代码、训练模型与脚本、评测框架、原子执行试验，以及论文 LaTeX 和可编辑方法图。

**当前是研究开发快照，尚不能用于复现论文中的完整成功率。** 论文表格保留“规划预估”标注，特征图保留“合成示意”标注。数据集、模型权重、账户信息和内部资源调度脚本不随仓库发布。

## 方法

文本分支描述原子动作名称及字符串参数；action query 接地终点位姿；未来想象旨在用随原子类型变化的关键帧替代函数内部逻辑；动作专家输出连续控制。标注代码保留语义、对象绑定、终点位姿、关键帧、时序和来源证据，不把未确认标注自动升级为可信监督。

## 当前完成范围

- 标注：DROID、LIBERO、RoboTwin 的转换、事件分析、质量门槛与测试；正式训练集仍需通过发布门槛。GenieSim 不在当前数据源策略中，历史工具可能保留相关分支。
- 训练：从实际训练服务器读取的最新 full-parameter 两阶段实现、RGB/pose 头、Query 前缀动作专家、数据加载与检查点。
- 评测：manifest、结果统计、JSON/CSV、TensorBoard 和适配器接口；真实 rollout、模型消融和 checkpoint 特征提取还未完整接通。
- 论文：当前本地已验证快照、参考文献、图像、可编辑 PPT 和合成特征图脚本。

先前“H100 验证通过”的表述范围过大：该评测任务实际只运行接口 mock，并读取 READY.json，未加载权重或运行真实模型推理。183 条接口记录不能当作真实评测。
